## مولد العقود العربية (Arabic Contract Generator)
تطبيق ويب بسيط باستخدام Streamlit لتوليد عقود عربية احترافية بالاعتماد على نماذج عقود عربية محلية ودعم نموذج Gemini من Google.

## نظرة عامة
- واجهة عربية مبسطة لإدخال بيانات العقد.
- استرجاع سياق من قوالب العقود العربية (مصري) لتحسين الصياغة والبنود.
- توليد نص عقد عربي متكامل عبر نموذج Gemini.

## المتطلبات
- Python 3.10+
- حساب Google AI Studio للحصول على مفتاح Gemini API.

## التثبيت
```bash
pip install streamlit google-generativeai langchain-community sentence-transformers faiss-cpu unstructured
```

ملاحظة: قد تحتاج باكدجات إضافية لمعالجات ملفات Word بحسب نظامك.

## الإعداد
1) أنشئ متغير بيئة لمفتاح Gemini API (مستحسن):
   - Windows PowerShell:
   ```bash
   setx GEMINI_API_KEY "YOUR_API_KEY"
   ```

2) ضع قوالب العقود العربية في المسار التالي داخل المستودع:
```
نماذج عقود/مصري - Copy/
```

## التشغيل
```bash
streamlit run app.py
```
سيفتح المتصفح على العنوان المحلي المعروض من Streamlit.

## كيفية الاستخدام
1) اختر تصنيف العقد (بيع، إيجار، مقاولة، …).
2) أدخل بيانات الأطراف، المدة، القانون الحاكم، القيمة، وشروط الدفع.
3) اضغط "إنشاء العقد" للحصول على النص النهائي وتنزيله.

## النماذج المدعومة (أمثلة)
- عقود البيع: بيع عقار، بيع شقة، بيع سيارة، بيع محل تجاري…
- عقود الإيجار: إيجار محل تجاري، إيجار سكني، إيجار سطح للإعلان…
- عقود المقاولة: مقاولة عامة، من الباطن، مع مهندس…
- عقود الوكالة/التوكيل: وكالة بالعمولة، توكيل شراء عقار…
- الهبة، القسمة، الفرانشايز، الطبع والنشر، السرية…

## الإعدادات داخل الكود
- في `app.py` يتم تهيئة نموذج Gemini. استخدم:
  - `gemini-2.5-flash` كنموذج افتراضي للأداء والسعر.
  - يمكنك تمرير مفتاح API عبر متغير البيئة `GEMINI_API_KEY` أو إدخاله في الشريط الجانبي.

## بنية المشروع
- `app.py`: تطبيق Streamlit لتوليد العقود العربية.
- `نماذج عقود/مصري - Copy/`: قوالب العقود العربية المستخدمة كمرجع.

## ملاحظات
- لا تضع مفتاح API داخل الكود. استخدم متغيرات البيئة.
- ناتج التوليد آلي ويحتاج مراجعة قانونية بشرية قبل الاستخدام الرسمي.

## الترخيص
استخدم حسب رغبتك. الرجاء احترام تراخيص وحقوق ملفات القوالب التي ترفعها.
